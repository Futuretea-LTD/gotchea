# gotchea-core

> The comprehension engine behind [gotchea](https://www.npmjs.com/package/gotchea): chunking, question pools and spaced-repetition scoring for codebases.

**This is a library package.** It is used internally by the `gotchea` CLI and MCP server. End users should not install it; run the tool instead:

```sh
npx gotchea init
```

If you are building on the engine directly:

```sh
npm install gotchea-core
```

It is ESM only and requires Node.js >= 20. The API is not stable yet and may change in any `0.x` release.
